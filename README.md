# 🎓 Student Grade Calculator (C)

A simple console-based C program that takes marks for 5 subjects and calculates the total marks, percentage, and final grade.

## ✨ C Concepts Used
- **Arrays:** Storing marks of 5 subjects (`int marks[5]`).
- **Loops:** Using a `for` loop for input and sum calculation.
- **Conditional Statements:** `if-else if-else` ladder for grade assignment.
- **Standard I/O:** `printf()` and `scanf()` from `<stdio.h>`.

## 🛠️ Tech Stack
- **Language:** C
